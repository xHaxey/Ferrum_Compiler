# Ferrum

Ferrum is a hobby programming language written in C++ and powered by LLVM.

Current features:

- Variables
- Arithmetic expressions
- Type checking
- Functions
- Function calls
- LLVM code generation
- Native executable generation

Requirements:

- LLVM 18.1.8 best
- Clang++ 18+
- Visual Studio 2022

Ferrum is in early development.

Currently Implemented:
- Variables
- Functions

Near future:
- String operations
- If expressions
- Loops

How to use:

./ferrum_compiler [project_dir] [fileNames]

After successful compilation .obj and .exe files will be in [project_dir]/build.
